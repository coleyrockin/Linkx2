## About

Linkx2 is a customizable link-in-bio page inspired by Linktree. Built with React and styled with Tailwind CSS, it provides a clean, responsive layout for showcasing social profiles, projects, and other important links from a single page.

## Features

- **Clean link layout** — minimal, focused design for maximum link visibility
- **Tailwind CSS styling** — utility-first CSS for rapid, consistent design
- **React Icons** — icon support for social platforms and link categories
- **Google Fonts** — custom typography for a polished look
- **Responsive design** — mobile-first layout that works on any screen size
- **Easy customization** — update links and styling through component props

## Getting Started

```bash
# Clone the repository
git clone https://github.com/coleyrockin/Linkx2.git

# Navigate to the project
cd Linkx2

# Install dependencies
npm install

# Start the development server
npm start
```

Open `http://localhost:3000` to view in the browser.
